ANDROID

Android 手機

用 USB 偵錯線直接抓 FPS、CPU、GPU、PSS、耗電、溫度。

  1. 到「設定 → 關於手機」，對「版本號碼」連點 7 次，開出「開發人員選項」。
  2. 回「設定 → 系統 → 開發人員選項」，把「USB 偵錯」打開。
  3. 用一條能傳資料的線（不要純充電線）把手機接上 Mac。
  4. 手機跳出「允許 USB 偵錯嗎？」時，按「允許」（可勾「一律允許這台電腦」）。
  5. 右側狀態變「已連線」並出現序號，按「進到 Lab」開始錄製。

iPHONE

iPhone

iPhone 的錄製本輪尚未整合，這張卡先把通道準備好，之後採集會接上。

  1. 打開 macOS 終端機，跑一次：brew install pipx && pipx ensurepath（重開 shell）再 pipx install pymobiledevice3（安裝 iPhone 通道工具）。
  2. 用 Lightning / USB-C 線把 iPhone 接上 Mac。
  3. iPhone 跳出「信任這部電腦」，按「信任」並輸入螢幕密碼。
  4. iPhone 開「開發者模式」（設定 → 隱私與安全性 → 開發者模式）。
  5. iPhone 是 iOS 17 以上的話：再開一個新的終端機視窗（Cmd+N），貼上 sudo pymobiledevice3 remote tunneld 按 Enter。它會要你輸入 Mac 的登入密碼（打字時畫面不會顯示，正常，打完按 Enter）。跳出一串連線訊息＝通道建好了，這個視窗縮小放旁邊、不要關。
  6. tunneld 跑起來後，iPhone 螢幕會「再」跳一次配對確認——回到手機上按「信任／允許」並輸入解鎖密碼（終端機那邊卡在 Waiting user pairing consent 就是在等這個）。
  7. 右側狀態變「已偵測到 iPhone」，按「進到 Lab」（本輪 iPhone 只能預覽，不能錄製）。
